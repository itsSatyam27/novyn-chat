Good to know

Questions, answered.

How do I install Novyn on Android?

Download the APK from the latest release and open it. Android may ask you to allow installs from your browser or file manager the first time. After that, you can check for updates from About Novyn inside the app.

Can I use Novyn without installing anything?

Yes. Open Novyn Web in any modern browser and sign in with your account.

How do invite links work?

When a friend shares an invite link, it opens Novyn straight to their profile so you can add them. If you do not have the app yet, this page offers the Android download.
