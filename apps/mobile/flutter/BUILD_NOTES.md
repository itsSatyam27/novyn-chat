# Novyn Android build notes

This file records the feature set included in the ARM64 Android release build.

- Automatic update checks on app startup/resume and periodic background checks.
- New-version notifications that open About Novyn.
- Update downloads continue when navigating away from About Novyn.
- Partial APK downloads are retained for resume after interruption.
- Download progress and errors are displayed in About Novyn.
- SHA-256 verification before installation.
- User-facing version label: Beta v1.0; internal build number remains separate.
- Installer-compatible persistent storage for the verified ARM64 APK.
- Includes the latest Call and About Novyn UI changes.
